OPCIÓN A: WINDOWS - Programador de Tareas
──────────────────────────────────────────

1. Abre "Programador de tareas" (busca en Windows)
2. Click en "Crear tarea básica"
3. Nombre: "GenerarReportesVentas"
4. Trigger: Diaria a las 6:00 AM
5. Acción: Ejecutar programa
   - Programa: python
   - Argumentos: C:\ruta\a\AUTOMATIZAR_TODO.py
   - Iniciar en: C:\ruta\a\carpeta\proyecto
6. Guardar

¡LISTO! Se ejecutará automáticamente cada día a las 6 AM

OPCIÓN B: LINUX/MAC - Cron
────────────────────────

Abre terminal y ejecuta:

    crontab -e

Agrega esta línea (ejecuta a las 6 AM diariamente):

    0 6 * * * cd /ruta/a/proyecto && python AUTOMATIZAR_TODO.py

Guarda y listo!

SOLUCIÓN DE PROBLEMAS
═══════════════════════════════════════════════════════════════════════════════

❌ "python: El término no se reconoce"
✓ Solución: Reinstala Python y marca "Add Python to PATH"
✓ O usa: C:\Python313\python.exe AUTOMATIZAR_TODO.py

❌ "ModuleNotFoundError: No module named 'pandas'"
✓ Solución: Ejecuta: python -m pip install pandas openpyxl -q

❌ "Archivo no encontrado: Orden de venta..."
✓ Solución: El CSV debe estar en LA MISMA CARPETA que el script
✓ Verifica el nombre exacto (mayúsculas, acentos, espacios)

❌ Script tarda mucho
✓ Normal: Con 41 órdenes tarda ~30 segundos
✓ Con 10,000 órdenes tarda ~2 minutos
