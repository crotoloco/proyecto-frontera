# Sistema actual

El sistema actual se conserva funcionando desde la raiz del proyecto:

- `scripts/`: procesamiento y generadores existentes.
- `data/`: exportaciones CSV/XLSX.
- `reports/`: resultados generados.
- `dashboard.html`, `inventario.html` y `monitor.html`: vistas actuales.

No se duplican archivos aqui. Esta carpeta documenta el nucleo heredado mientras se integra la nueva interfaz del Centro de Control.
